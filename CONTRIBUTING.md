# Contributing

Bug reports, compatibility tests, and source improvements are welcome.
Describe the game, GPU, driver and RTSS versions when reporting behavior.
Use the test checklist in `docs/TESTING.md`.

Keep the runtime read-only with respect to game and driver settings. Do not
add telemetry or network access without clearly discussing it first.

Build with official Zig 0.15.2. Run `Test.ps1` before sending a change.
By contributing, you agree to make your contribution available under the
repository's MIT License.
